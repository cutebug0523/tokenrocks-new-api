TokenRocks 使用指南

一个 API 密钥调用 DeepSeek、Qwen、Claude、GPT 等主流模型，按量计费，价格低至官方价的 0.5 折，余额不过期。

接口信息

OpenAI 兼容地址
https://api.tokenrocks.ai/v1（Chat Completions、Responses、图片生成）
Anthropic 原生地址
https://api.tokenrocks.ai（Messages 接口，Claude 系客户端用这个）
API 密钥
在控制台「API 密钥」页创建，形如 sk-xxxx
模型名
见 模型广场，例如 deepseek-v4.1-flash、claude-opus-5-5
大部分客户端只要填「接口地址 + API 密钥 + 模型名」三样就能用。填接口地址时注意：要求填到 /v1 的客户端填 https://api.tokenrocks.ai/v1，会自己拼 /v1 的填 https://api.tokenrocks.ai。

三步快速上手

  1. 注册并充值
    在 注册页 用邮箱注册（验证码邮件没收到就看看垃圾箱）。新用户送少量体验额度；正式使用请到控制台「钱包」用兑换码充值，详见 充值。
  2. 创建 API 密钥
    控制台 →「API 密钥」→ 创建 API 密钥。名称随便填；分组保持默认的「auto」（自动）即可，它会按模型自动选最便宜的可用线路。想固定走某条线路时再手动选分组，见 分组说明。
  3. 填进客户端开始调用
    把接口地址、密钥、模型名填进你用的工具（见 客户端配置），或者先用下面的命令测一下：
curl https://api.tokenrocks.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-v4.1-flash", "messages": [{"role": "user", "content": "你好"}]}'

返回一段 JSON 回复就说明通了。调用记录和扣费明细在控制台「使用日志」里查。

分组说明

分组决定走哪条线路、按什么折扣计费。价格都是相对官方价打折，每个模型的具体价格见 模型广场（卡片上的划线价就是官方价）。

分组包含模型价格适合
auto（自动）全部按实际走的分组计费不知道选什么就用它，按模型自动选最便宜的可用分组
国模特价DeepSeek、Qwen0.5折日常使用、批量任务，性价比最高
国模企业满血DeepSeek3折对稳定性和效果要求高的生产场景
国外特价Claude、GPTClaude 0.6折，GPT 0.5折个人开发、编码助手，性价比优先
国外企业满血Claude、GPTClaude 3折，GPT 1.2折团队与生产环境，稳定优先
生图GPT Image、Nano Banana按张计费图片生成与改图

auto 的选择顺序：国模特价 → 国外特价 → 生图 → 国模企业满血 → 国外企业满血，取第一个有该模型的分组。所以 auto 默认走特价线路，想用企业满血请手动选分组。

「特价」和「企业满血」有什么区别？

  • 特价：低价线路，价格最便宜。个别模型的上游会在请求里附带固定的系统提示词，多计少量输入 token（通常能命中缓存，影响很小）；高峰期偶尔会慢。
  • 企业满血：保真线路，走官方原版模型，稳定优先，适合正式项目。
  • 同一个模型名在两个分组里都可以用，区别只在线路和价格。
报错「分组 xxx 下模型 yyy 无可用渠道」，说明这个密钥所在分组里没有这个模型（例如在「国模特价」里调 Claude）。到「API 密钥」页把分组改成 auto 或对应分组即可。

客户端配置

Cherry Studio 等聊天客户端

控制台「API 密钥」页，点密钥右侧的「聊天」可以一键导入到 Cherry Studio、CC Switch、DeepChat、Lobe Chat 等客户端。手动配置时：服务商类型选 OpenAI 兼容，接口地址 https://api.tokenrocks.ai，填入密钥，再添加要用的模型名。

Claude Code

设置环境变量后启动即可（Windows 用 set 或在系统环境变量里配置）：

export ANTHROPIC_BASE_URL=https://api.tokenrocks.ai
export ANTHROPIC_AUTH_TOKEN=sk-你的密钥
export ANTHROPIC_MODEL=claude-opus-5-5
claude

也可以用 CC Switch 一键导入，省去手动配置。

代码调用（Python）

from openai import OpenAI

client = OpenAI(base_url="https://api.tokenrocks.ai/v1", api_key="sk-你的密钥")
reply = client.chat.completions.create(
    model="deepseek-v4.1-flash",
    messages=[{"role": "user", "content": "你好"}],
)
print(reply.choices[0].message.content)

Claude 模型也可以用 Anthropic 官方 SDK：Anthropic(base_url="https://api.tokenrocks.ai", api_key="sk-你的密钥")。

常见问题

价格是怎么算的？token 是什么？

模型按 token 计费，价格写成「每百万 token 多少元」。token 是模型处理文字的单位，中文一个字大约对应 1 个 token。输入（你发的）、输出（模型回的）、缓存（重复发送的上下文命中缓存）分别计价，缓存价格最便宜。图片生成按张计费。

报错「无可用渠道」

密钥所在分组里没有这个模型，把密钥分组改成 auto，或换成包含该模型的分组。也可能是模型名写错了，模型名以模型广场为准。

报错「额度不足」或「余额不足」

到「钱包」用兑换码充值。如果给密钥单独设置了额度上限，也可能是密钥额度用完了，在「API 密钥」页编辑。

报错 401 / 无效的令牌

检查密钥是否完整复制（以 sk- 开头）、是否被禁用或过期；接口地址要用 api.tokenrocks.ai，不要填官网页面地址。

回复很慢或超时

大模型首字一般需要几秒到十几秒，长回复建议开启流式输出（stream）。特价线路高峰期可能变慢，着急的任务可以换企业满血分组。

余额会过期吗？可以退款吗？

余额不过期。兑换码兑换后不支持退回；如果遇到兑换码无效、扣费异常，请带上截图联系站长微信 cutebug0523。

控制台「使用日志」里有每次调用的模型、token 数和扣费金额；「数据看板」可以看按天汇总。
