编程客户端配置

DeepSeek Harness、ZCode、WorkBuddy 自己没有一键导入。最省事的是装 TR助手，点一下就配好；也可以按下面的步骤手动添加一次，以后打开就能用。截图里绿色框是要点或要填的地方，橙色框是 API 密钥，粘贴你自己的。看不清就点图片看大图。

装 TR助手，一键接入

TR助手装在电脑上，登录后点「接入」，就把 TokenRocks 写进本机的 DeepSeek Harness、ZCode、WorkBuddy：模型、上下文、看图、思考都设好，不用复制密钥、一项项填。菜单栏（Windows 是右下角托盘）里还能看余额，快用完了会提醒。

下载 Mac 版 Mac 版即将上线 下载 Windows 版 手机版即将上线现在只有电脑版，在电脑上打开这个页面下载

Mac 版 Apple 芯片和 Intel 都能用，打开后照窗口里的箭头，把图标拖进「应用程序」。Windows 版下载时，浏览器如果提示这个文件不常见，选「保留」（Edge 是点下载项右边的「…」→「保留」，弹出提示后点「显示更多」→「仍然保留」）；第一次打开如果提示「Windows 已保护你的电脑」，点「更多信息」再点「仍要运行」。不想装软件，就照下面的步骤手动添加。

先准备好

三个客户端都填同样的东西：

接口地址https://api.tokenrocks.ai/v1
协议Responses（不要选 Chat Completions）
API 密钥在控制台「API 密钥」页创建，形如 sk-xxxx

每个模型这样设：

模型名上下文最大输出图片思考
deepseek-v4.1-flash1024000128000勾开
deepseek-v4-pro1024000128000不勾开
glm-5.31024000128000不勾开
glm-5.3-flash1024000128000勾开
kimi-k3.1-pro1024000128000勾开

glm-5.3 和 deepseek-v4-pro 不支持看图，glm-5.3 的 flash 版反而支持。用不到的模型可以不加，其他模型名见模型与价格。

API 密钥只粘贴在客户端的「API 密钥 / API Key」框里，不要发给别人。截图里这个框是空的，就是要你粘贴的地方。

DeepSeek Harness

要用「自定义模型 API」。「第三方模型提供商」那一栏是内置的官方服务商，填不了接口地址。

1. 打开设置

  1. 点左下角「··· 更多」
  2. 点「设置」

2. 添加模型提供商

  1. 左边选「模型」
  2. 点「添加模型提供商」

3. 填提供商信息

  1. 切到「自定义模型 API」
  2. Provider ID 填 tokenrocks
  3. 显示名称填 TokenRocks
  4. API 地址填 https://api.tokenrocks.ai/v1
  5. API 协议选「OpenAI Responses」
  6. API 密钥粘贴你的密钥

4. 添加模型

  1. 确认 API 密钥已经粘贴（sk- 开头）
  2. 模型目录里依次填模型名，显示名称可以空着
  3. 每个模型点右边的「>」展开，按下一步设置
  4. 点「添加模型」加下一个

5. 设上下文、图片和推理

  1. 上下文窗口 1024000，最大输出 128000
  2. 输入类型勾「文本」和「图片」；glm-5.3、deepseek-v4-pro 只勾文本
  3. 打开「推理等级」
  4. 档位用默认的 off / low / medium / high，不用改
  5. 所有模型设好后，点「创建提供商」

6. 完成

  1. 列表里出现「TokenRocks 自定义」就配好了
  1. 聊天时在 TokenRocks 分组里选模型
  2. 输入框右下角点这里切换模型

ZCode

ZCode 的「智能配置」能认出这几个模型，会自动填好图片和推理等级，你只需要改上下文和最大输出。

1. 第一次打开：跳过登录

已经进到工作区的直接看第 2 步。

  1. 点「使用 API key」
  1. 点「暂时跳过」（这一页的 API Key 是智谱官方的，不用填）

2. 添加供应商

  1. 点左下角齿轮进设置，选「模型设置」
  2. 点右上角「+ 添加供应商」
  1. 点「创建自定义供应商」

3. 填地址，选 Responses

  1. Base URL 填 https://api.tokenrocks.ai/v1
  2. API 格式选「Responses (/responses)」

选好格式后下面会多出 API Key 框，把 API 密钥粘贴进去（见第 6 步的图）。

4. 添加模型

点「模型列表」右边的「+ 添加模型」。

  1. 「智能配置」保持打开
  2. 填模型名，比如 deepseek-v4.1-flash
  3. 上下文窗口改成 1024000
  4. 最大输出 Token 改成 128000
  5. 展开「高级配置」
  6. 输入类型只勾「文本」「图片」；视频、PDF 如果被自动勾上，取消掉
  7. 推理等级是自动填的，不用改
  8. 点「保存」，每个模型各加一次

5. glm-5.3、deepseek-v4-pro 不勾图片

  1. 加 glm-5.3、deepseek-v4-pro 时，输入类型只留「文本」

6. 粘贴 API 密钥，检查列表

  1. API Key 粘贴你的密钥
  2. 还没加完就继续点「添加模型」
  3. 模型都显示 1M；除了 glm-5.3 和 deepseek-v4-pro，其余都带「视觉」标签

供应商默认叫「新供应商」，想改名点右上角「···」→「重命名」，不改也能用。配好后回到工作区，聊天时在模型选择里选这些模型。

WorkBuddy

WorkBuddy 一次只能加一个模型，第 3～5 步每个模型走一遍。

1. 打开设置

  1. 点左下角自己的头像
  1. 点「设置」

2. 进入自定义模型

  1. 左边选「模型」
  2. 点「添加模型」

3. 供应商选「自定义」

  1. 点开供应商下拉（默认是腾讯云）
  2. 搜「自定义」
  3. 选「自定义」

4. 填地址、API 密钥、模型名称

  1. 接口地址填 https://api.tokenrocks.ai/v1（框里灰色的提示是一长串地址，不用管，填到 /v1 就行）
  2. API Key 粘贴你的密钥
  3. 模型名称填模型名，比如 deepseek-v4.1-flash

5. 往下滚，勾图片和思考，填上下文

  1. 勾「图片输入」和「思考模式」；glm-5.3、deepseek-v4-pro 不勾图片输入（「工具调用」「允许关闭思考」默认勾着，保留）
  2. 支持的思考强度勾「低」「中」「高」
  3. 输入填 1024000，输出填 128000
  4. 点「保存」，再点「添加模型」加下一个

6. 完成

  1. 加好的模型都在列表里
  1. 在「自定义模型」分组里选，别选成上面 WorkBuddy 自带的同名模型
  2. 输入框右下角点这里切换模型

Claude Code 国内怎么装

Claude Code 官网的安装命令（claude.ai/install.sh）在国内会跳到「所在地区不可用」，装不上。用 npm 从国内镜像装，不用梯子：

  1. 装 Node.js：打开 nodejs.org/zh-cn/download，下载「LTS」版的安装包（Windows 是 .msi，Mac 是 .pkg），双击一路「下一步」装好。装过的跳过这步。
  2. 打开命令行：Windows 在开始菜单搜「命令提示符」打开（别用 PowerShell，它默认不让运行 npm）；Mac 打开「终端」。
  3. 粘贴下面这行回车，等它装完（一两分钟）：
    Windows（命令提示符）
    npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
    Mac（终端，会让你输开机密码，输的时候不显示，输完回车）
    sudo npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
  4. 输入 claude --version 回车，出来版本号就装好了。
  5. 回 TR助手 点「接入」，勾上 Claude Code；以后在 TR助手 首页点它的图标就能打开。不用 TR助手 的，按使用指南设环境变量。

Windows 上提示「npm 不是内部或外部命令」：Node.js 刚装完，把命令提示符关掉重新打开再试。
