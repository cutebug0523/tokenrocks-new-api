常见问题

接口地址填什么？

OpenAI 兼容客户端填 https://api.tokenrocks.ai/v1，Claude Code 等填 https://api.tokenrocks.ai。用 DeepSeek Harness、WorkBuddy、ZCode 的，看客户端图文教程；其他见使用指南。

DeepSeek Harness、ZCode、WorkBuddy 能一键接入吗？

能。装 TR助手，登录后点一下就把这三个客户端配好，菜单栏（Windows 是右下角托盘）里还能看余额。不想装软件，也可以照图文教程手动添加。

特价、平价和企业满血有什么区别？

国模平价的线路经过长对话实测筛选，缓存稳定，国产模型日常用推荐；特价最便宜，但已停止维护，高峰可能卡顿报错，能用就用；企业满血走官方原版模型，稳定优先。

怎么充值？余额会过期吗？

控制台「钱包」用支付宝在线充值，付完自动到账；有兑换码也可以在钱包页兑换。余额不过期。
