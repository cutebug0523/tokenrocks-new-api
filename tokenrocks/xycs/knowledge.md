- 我们是 OpenAI 兼容接口（Chat Completions）。软件里要有「自定义模型 / 自定义服务商 / 自定义 API」这类入口，能自己填接口地址、密钥、模型名，才接得上。只能登录自家账号，或者只能从它列出的几家供应商里选的，接不了。

  - CodeBuddy（腾讯）：添加自定义模型，服务商选兼容格式（界面上写的是 OpenAI Compatible）；改配置文件的话，地址要写全到 https://api.tokenrocks.ai/v1/chat/completions。
  - WorkBuddy（腾讯）：头像 → 设置 → 模型 → 自定义，地址填 https://api.tokenrocks.ai/v1（它会自动补全后面的路径），再填密钥和模型名。
  - Kimi Code 命令行版：用 /provider 命令，或者在它的配置文件里加一个兼容格式的服务商（配置里的类型名是 openai），base_url 填 https://api.tokenrocks.ai/v1。
  - ZCode（智谱）：添加服务商，填地址、选 Chat completions、填密钥，再添加模型。
  - Qwen Code（阿里的命令行工具）：设置环境变量，接口地址 https://api.tokenrocks.ai/v1，再填密钥和模型名。
  - Cherry Studio：设置 → 模型服务 → 添加，类型选兼容格式（界面上写的是 OpenAI），地址填 https://api.tokenrocks.ai。
  - Chatbox：设置里选兼容格式（界面上写的是 OpenAI API Compatible），地址填 https://api.tokenrocks.ai。
